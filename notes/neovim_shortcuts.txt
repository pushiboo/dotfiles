# Core Folding Shortcuts in Neovim
  za: Toggle the fold at the cursor (open if closed, close if open). 
  zc: Close (fold) the current fold under the cursor. 
  zo: Open (unfold) the current fold under the cursor. 
  zR: Open all folds recursively. 
  zM: Close all folds recursively. 
  zd: Delete the fold at the cursor (removes fold marker only). 
  zD: Recursively delete all folds at the cursor.
# Navigation Between Folds
  zj: Move cursor to the next fold. 
  zk: Move cursor to the previous fold.
# Creating Folds
  zf{motion}: Create a fold using a motion (e.g., zf3j folds current line and next 3 lines). 
  zf in Visual mode: Select lines and press zf to create a fold. 
  zfa}: Create a fold from the current line to the matching closing brace (}). 
# Customizing Fold Behavior
#  Set fold method: 
    :set foldmethod=indent (default),
    :set foldmethod=expr (for Tree-sitter),or
    :set foldmethod=manual.
#  Use :set foldcolumn=1 to show fold column (sidebar).
#  Enable foldlevelstart=1 to open top-level folds by default.
#  Use foldnestmax=4 to limit nesting depth for cleaner folds. 


# Changing modes
  <ESC>
    Exit from other modes into NORMAL mode
  i/I
    Enter INSERT mode, cursor placed before the current charac­ter­/first character in line
  a/A
    Enter INSERT mode, cursor placed after the current charac­ter/the end of the line
  o/O
    Creates a new, empty line below/­above the cursor, and enter INSERT mode
  v
    Enter Visual mode, cursor movement selection
  V
    Enter Visual mode, line selection
  <CTRL>-v
    Enter Visual mode, block selection
  :
  Enter COMMAN­D-LINE mode
